
# Mammoth `eval2` documentation

This documentation set describes the supplied `eval2` evaluation workflow.

- **[USER.md](USER.md)** — user-facing workflow, main targets, outputs, status/reporting.
- **[PORTING.md](PORTING.md)** — practical porting notes.
- **[DEVELOPER.md](DEVELOPER.md)** — component architecture, Make fragments and subtargets, Python/shell components, state model, portability matrix, and developer porting/refactoring notes.

The documentation intentionally separates the mostly generic **evaluation planning/reporting** layer from the current **LUMI/Slurm execution** layer.
