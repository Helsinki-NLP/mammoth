Configuration¶

-config, --config

Path of the main YAML config file.

-save_config, --save_config

Path where to save the config.

Data/Tasks¶

-tasks, --tasks

List of datasets and their specifications. See examples/*.yaml for further details.

-transforms, --transforms

Possible choices: denoising, prefix, filterfeats, inferfeats, switchout, tokendrop, tokenmask, filtertoolong, filterwordratio, filterrepetitions, filterterminalpunct, filternonzeronumerals, sentencepiece, bpe

Default transform pipeline to apply to data. Can be specified in each corpus of data to override.

Default: []

Vocab¶

-src_vocab, --src_vocab

Path to src (or shared) vocabulary file. Format: one <word> or <word> <count> per line.

-tgt_vocab, --tgt_vocab

Path to tgt vocabulary file. Format: one <word> or <word> <count> per line.

-src_vocab_size, --src_vocab_size

Maximum size of the source vocabulary; will silently truncate your vocab file if longer.

-tgt_vocab_size, --tgt_vocab_size

Maximum size of the target vocabulary; will silently truncate your vocab file if longer.

-use_hf_tokenizer, --use_hf_tokenizer

Use HuggingFace tokenizers instead of traditional vocab files. Vocab paths should point to .json tokenizer files.

Default: False

-add_language_tokens, --add_language_tokens

Automatically add language prefix tokens (src_prefix/tgt_prefix from tasks) to HuggingFace tokenizers. Only applies when use_hf_tokenizer is True. Default: True

Default: True

-decoder_start_with_eos, --decoder_start_with_eos

BART-style decoder start: target sequences begin with </s> (EOS) followed by <s> (BOS). At inference, primes the decoder with </s> instead of <s>. Required for BART checkpoints.

Default: False

Transform/Denoising AE¶

--permute_sent_ratio, -permute_sent_ratio

Permute this proportion of sentences (boundaries defined by [‘.’, ‘?’, ‘!’]) in all inputs.

Default: 0.0

--rotate_ratio, -rotate_ratio

Rotate this proportion of inputs.

Default: 0.0

--insert_ratio, -insert_ratio

Insert this percentage of additional random tokens.

Default: 0.0

--random_ratio, -random_ratio

Instead of using <mask>, use random token this often. Incompatible with MASS

Default: 0.0

--mask_ratio, -mask_ratio

Fraction of words/subwords that will be masked.

Default: 0.0

--mask_length, -mask_length

Possible choices: subword, word, span-poisson

Length of masking window to apply.

Default: 'subword'

--poisson_lambda, -poisson_lambda

Lambda for Poisson distribution to sample span length if -mask_length set to span-poisson.

Default: 3.0

--replace_length, -replace_length

Possible choices: -1, 0, 1

When masking N tokens, replace with 0, 1, or N tokens. (use -1 for N)

Default: -1

--denoising_objective

Possible choices: bart, mass

choose between BART-style or MASS-style denoising objectives

Default: 'bart'

Transform/InferFeats¶

--reversible_tokenization, -reversible_tokenization

Possible choices: joiner, spacer

Type of reversible tokenization applied on the tokenizer.

Default: 'joiner'

--prior_tokenization, -prior_tokenization

Whether the input has already been tokenized.

Default: False

Transform/SwitchOut¶

-switchout_temperature, --switchout_temperature

Sampling temperature for SwitchOut. \(\tau^{-1}\) in [WPDN18]. Smaller value makes data more diverse.

Default: 1.0

Transform/Token_Drop¶

-tokendrop_temperature, --tokendrop_temperature

Sampling temperature for token deletion.

Default: 1.0

Transform/Token_Mask¶

-tokenmask_temperature, --tokenmask_temperature

Sampling temperature for token masking.

Default: 1.0

Transform/Length filter¶

--src_seq_length_max, -src_seq_length_max

Maximum source sequence length.

Default: 200

--tgt_seq_length_max, -tgt_seq_length_max

Maximum target sequence length.

Default: 200

--src_seq_length_min, -src_seq_length_min

Minimum source sequence length.

Default: 1

--tgt_seq_length_min, -tgt_seq_length_min

Minimum target sequence length.

Default: 1

Transform/Word ratio filter¶

--word_ratio_threshold, -word_ratio_threshold

Threshold for discarding sentences based on word ratio.

Default: 3

Transform/Repetitions filter¶

--rep_threshold, -rep_threshold

Number of times the substring is repeated.

Default: 2

--rep_min_len, -rep_min_len

Minimum length of the repeated pattern.

Default: 3

--rep_max_len, -rep_max_len

Maximum length of the repeated pattern.

Default: 100

Transform/Terminal punctuation filter¶

--punct_threshold, -punct_threshold

Minimum penalty score for discarding sentences based on their terminal punctuation signs

Default: -2

Transform/Non-zero numerals filter¶

--nonzero_threshold, -nonzero_threshold

Threshold for discarding sentences based on numerals between the segments with zeros removed

Default: 0.5

Transform/Subword/Common¶

Attention

Common options shared by all subword transforms. Including options for indicate subword model path, Subword Regularization/BPE-Dropout, and Vocabulary Restriction.

-src_subword_model, --src_subword_model

Path of subword model for src (or shared).

-tgt_subword_model, --tgt_subword_model

Path of subword model for tgt.

-src_subword_nbest, --src_subword_nbest

Number of candidates in subword regularization. Valid for unigram sampling, invalid for BPE-dropout. (source side)

Default: 1

-tgt_subword_nbest, --tgt_subword_nbest

Number of candidates in subword regularization. Valid for unigram sampling, invalid for BPE-dropout. (target side)

Default: 1

-src_subword_alpha, --src_subword_alpha

Smoothing parameter for sentencepiece unigram sampling, and dropout probability for BPE-dropout. (source side)

Default: 0

-tgt_subword_alpha, --tgt_subword_alpha

Smoothing parameter for sentencepiece unigram sampling, and dropout probability for BPE-dropout. (target side)

Default: 0

-src_subword_type, --src_subword_type

Possible choices: sentencepiece, bpe, none

Type of subword tokenization for source side. Used by denoising transforms to determine word boundaries.

Default: 'sentencepiece'

-tgt_subword_type, --tgt_subword_type

Possible choices: sentencepiece, bpe, none

Type of subword tokenization for target side. Used by denoising transforms to determine word boundaries.

Default: 'sentencepiece'

-src_subword_vocab, --src_subword_vocab

Path to the vocabulary file for src subword. Format: <word> <count> per line.

Default: ''

-tgt_subword_vocab, --tgt_subword_vocab

Path to the vocabulary file for tgt subword. Format: <word> <count> per line.

Default: ''

-src_vocab_threshold, --src_vocab_threshold

Only produce src subword in src_subword_vocab with frequency >= src_vocab_threshold.

Default: 0

-tgt_vocab_threshold, --tgt_vocab_threshold

Only produce tgt subword in tgt_subword_vocab with frequency >= tgt_vocab_threshold.

Default: 0

-share_vocab, --share_vocab

use the same model for both sides

Default: False

Model- Embeddings¶

--enable_embeddingless, -enable_embeddingless

Enable the use of byte-based embeddingless models(Shaham et. al, 2021) https://aclanthology.org/2021.naacl-main.17/

Default: False

--share_encoder_decoder_embeddings, -share_encoder_decoder_embeddings

Share token embeddings between encoder and decoder. Only works when encoder and decoder use the same vocabulary and have matching model dimensions.

Default: False

Model- Encoder-Decoder¶

--model_type, -model_type

Possible choices: text

Type of source model to use. Allows the system to incorporate non-text inputs. Options are [text].

Default: 'text'

--model_dtype, -model_dtype

Possible choices: fp32, fp16, bf16

Data type of the model. For LUMI (MI250X based), bf16 is recommended. For Puhti (V100 based), fp32 is recommended.

Default: 'fp32'

--enc_layers, -enc_layers

Number of layers in each encoder module

--dec_layers, -dec_layers

Number of layers in each decoder module

--model_dim, -model_dim

Size of Transformer representations (shared for encoder and decoder). Mutually exclusive with enc_model_dim / dec_model_dim.

Default: -1

--enc_model_dim, -enc_model_dim

Encoder hidden dimension. Must be set together with dec_model_dim. Mutually exclusive with model_dim.

--dec_model_dim, -dec_model_dim

Decoder hidden dimension. Must be set together with enc_model_dim. Mutually exclusive with model_dim.

Model- Attention¶

--enc_sliding_window, -enc_sliding_window

Sliding window size for encoder attention (total context, symmetric). -1 = disabled (full attention). Requires Flash Attention 2. Reduces memory for long sequences. Example: 128 = attend to ±64 tokens.

Default: -1

--dec_sliding_window, -dec_sliding_window

Sliding window size for decoder attention (total context, symmetric). -1 = disabled (full attention). Requires Flash Attention 2. Causal masking is automatically applied. Example: 128 = attend to ±64 tokens.

Default: -1

--enc_global_attn_every_n_layers, -enc_global_attn_every_n_layers

Encoder: every Nth layer uses global attention (full context), others use sliding window. Interleaved pattern from ModernBERT. Layer 0, N, 2N, … get global attention. Only applies if enc_sliding_window > 0. Default: 3

Default: 3

--dec_global_attn_every_n_layers, -dec_global_attn_every_n_layers

Decoder: every Nth layer uses global attention (full context), others use sliding window. Interleaved pattern from ModernBERT. Layer 0, N, 2N, … get global attention. Only applies if dec_sliding_window > 0. Default: 3

Default: 3

--enc_global_rope_theta, -enc_global_rope_theta

Encoder: RoPE theta for global attention layers (every Nth layer). Higher values allow for longer context modeling. Default: 160000.0 (ModernBERT style). Only applies if enc_sliding_window > 0 and rotary_pos_emb is enabled.

Default: 160000.0

--enc_local_rope_theta, -enc_local_rope_theta

Encoder: RoPE theta for local sliding window attention layers. Standard value for most transformer models. Default: 10000.0. Only applies if enc_sliding_window > 0 and rotary_pos_emb is enabled.

Default: 10000.0

--dec_global_rope_theta, -dec_global_rope_theta

Decoder: RoPE theta for global attention layers (every Nth layer). Higher values allow for longer context modeling. Default: 160000.0 (ModernBERT style). Only applies if dec_sliding_window > 0 and rotary_pos_emb is enabled.

Default: 160000.0

--dec_local_rope_theta, -dec_local_rope_theta

Decoder: RoPE theta for local sliding window attention layers. Standard value for most transformer models. Default: 10000.0. Only applies if dec_sliding_window > 0 and rotary_pos_emb is enabled.

Default: 10000.0

--max_relative_positions, -max_relative_positions

Maximum distance between inputs in relative positions representations. For more detailed information, see: https://arxiv.org/pdf/1803.02155.pdf

Default: 0

--heads, -heads

Number of attention heads. model_dim must be divisible by heads.

Default: 8

--ff_mult, -ff_mult

FFN inner dimension multiplier: ff_inner = model_dim * ff_mult. If unset, the default is chosen from ff_activation: 2.67 (≈ 8/3, matches parameter count of a 4× GELU FFN) for swiglu, 4.0 for gelu.

--ff_activation, -ff_activation

Possible choices: swiglu, gelu

Activation function for feed-forward layers in native transformer blocks. Choices: swiglu (default), gelu. SWiGLU uses 3 matrices (gate, up, down), GELU uses 2 matrices (up, down).

Default: 'swiglu'

--rotary_pos_emb, -rotary_pos_emb

Use rotary positional embeddings (RoPE) instead of absolute positional embeddings.

Default: False

--post_emb_norm, -post_emb_norm

Apply RMSNorm after the token embedding.

Default: False

--attn_dropout, -attn_dropout

Dropout probability inside attention (applied to the attention weights).

Default: 0.0

--ff_dropout, -ff_dropout

Dropout probability inside the feed-forward sublayer.

Default: 0.0

Generator¶

--generator_function, -generator_function

Possible choices: softmax

Which function to use for generating probabilities over the target vocabulary (choices: softmax)

Default: 'softmax'

--loss_scale, -loss_scale

For FP16 training, the static loss scale to use. If not set, the loss scale is dynamically computed.

Default: 0.0

--apex_opt_level, -apex_opt_level

Possible choices: O0, O1, O2, O3

For FP16 training, the opt_level to use. See https://nvidia.github.io/apex/amp.html#opts-levels.

Default: 'O1'

Attention bridge¶

--hidden_ab_size, -hidden_ab_size

Size of attention bridge hidden states

Default: 2048

--ab_fixed_length, -ab_fixed_length

Number of attention heads in attention bridge (fixed length of output)

Default: 50

--ab_layers, -ab_layers

Possible choices: lin, simple, transformer, perceiver, feedforward

Composition of the attention bridge

Default: []

--ab_layer_norm, -ab_layer_norm

Possible choices: none, rmsnorm, layernorm

Use layer normalization after lin, simple and feedforward bridge layers

Default: 'layernorm'

--ab_heads, -ab_heads

Number of heads for transformer self-attention. Semi-obsolete: not used for x-transformers, only used for some attention bridge configuations.

Default: 8

--dropout, -dropout

Dropout probability; Legacy: applied in the attention bridge

Default: [0.3]

--attention_dropout, -attention_dropout

Attention Dropout probability; Legacy: applied in the attention bridge

Default: [0.1]

General¶

--save_model, -save_model

Model filename (the model will be saved as <save_model>_N.pt where N is the number of steps

Default: 'model'

--save_checkpoint_steps, -save_checkpoint_steps

Save a checkpoint every X steps. Required when save_strategy=’steps’. Ignored for metric-based strategies (best_*), which save at validation time (–valid_steps).

Default: 0

--keep_checkpoint, -keep_checkpoint

Keep X checkpoints (negative: keep all). Works with –save_strategy to determine rotation behavior: FIFO for ‘steps’, metric-based for ‘best_only’/’best_and_last’/’best_n’.

Default: -1

--save_strategy, -save_strategy

Possible choices: steps, best_only, best_and_last, best_n

Checkpoint saving strategy:

‘steps’: Save every save_checkpoint_steps (FIFO rotation) ‘best_only’: Keep only the best checkpoint by metric (saves at validation time) ‘best_and_last’: Keep best + keep_checkpoint most recent (saves at validation time) ‘best_n’: Keep top keep_checkpoint checkpoints by metric (saves at validation time)

Note: Metric-based strategies (best_*) save at validation frequency (–valid_steps), not –save_checkpoint_steps. Use –keep_checkpoint to control how many to keep.

Default: 'steps'

--metric_for_best_model, -metric_for_best_model

Metric to use for determining best checkpoint. Options: ‘ppl’ (perplexity), ‘accuracy’, ‘bleu’, ‘chrf’, or custom metric name

Default: 'bleu'

--greater_is_better, -greater_is_better

Whether higher metric values are better. If None, auto-inferred: False for ppl, True for accuracy/bleu

--train_steps, -train_steps

Number of training steps

Default: 100000

--epochs, -epochs

Deprecated epochs see train_steps

Default: 0

--valid_steps, -valid_steps

Perfom validation every X steps

Default: 10000

Default: ''

--override_checkpoint_vocab, -override_checkpoint_vocab

When training from checkpoint, override the checkpoint’s vocabulary with the one specified in config. This allows using different tokenizers than the ones baked into the checkpoint. Default: False (use checkpoint vocabulary).

Default: False

--reset_optim, -reset_optim

Possible choices: none, all, states, keep_states

Controls which parts of optimizer to load from checkpoint when using –train_from. This is a 2x2 matrix of [Optimizer State] × [Training Step]: ‘none’: KEEP state + KEEP step → True resumption after interruption. Loads optimizer state (momentum, variance buffers) and continues from checkpoint’s training step. CRITICAL: Your config’s ‘optim’ must match the optimizer used to create the checkpoint. ‘keep_states’: KEEP state + RESET step to 1 → Restart LR schedule with same optimizer. Useful when you want to change learning rate schedule but preserve optimizer momentum. ‘states’: RESET state + KEEP step → Switch optimizer mid-training. Loads checkpoint’s training step but builds fresh optimizer state. Use when switching optimizer types (e.g., Adam → Adafactor). ‘all’: RESET state + RESET step to 1 → Fine-tuning from scratch. Only loads model weights, starts fresh training with new optimizer and step=1. IMPORTANT: Checkpoints do NOT save optimizer configuration (optim, learning_rate, etc). The optimizer type is ALWAYS from your config file, regardless of reset_optim value. Checkpoints only save: (1) model architecture, (2) model weights, (3) optimizer state buffers.

Default: 'none'

Default: False

Fine-grained Parameter Freezing¶

--freeze_encoder, -freeze_encoder

Freeze all encoder parameters (attention and feedforward layers). Does not affect embeddings unless –freeze_encoder_embeddings is also set. Adapters remain trainable if configured.

Default: False

--freeze_decoder, -freeze_decoder

Freeze all decoder parameters (self-attention, cross-attention, feedforward, sandwich-norm post-branch norms where present, and the vocabulary output projection). Does not affect embeddings unless –freeze_decoder_embeddings is also set. Adapters remain trainable if configured. Can be combined with –freeze_cross_attention=false to keep only cross-attention trainable.

Default: False

--freeze_encoder_embeddings, -freeze_encoder_embeddings

Freeze encoder token embeddings and the shared post-embedding norm. Can be used independently or with –freeze_encoder.

Default: False

--freeze_decoder_embeddings, -freeze_decoder_embeddings

Freeze decoder token embeddings and the shared post-embedding norm. Can be used independently or with –freeze_decoder.

Default: False

--freeze_cross_attention, -freeze_cross_attention

Freeze only cross-attention layers in the decoder. Useful for adapting decoder to new encoder representations while preserving the encoder-decoder alignment learned during pretraining. Mutually exclusive with –freeze_decoder (decoder freeze takes precedence).

Default: False

--freeze_attention_bridge, -freeze_attention_bridge

Freeze the attention bridge between encoder and decoder if present. Only applies when attention bridge is configured (ab_layers is not empty) and encoder/decoder dimensions match. Has no effect if attention bridge does not exist.

Default: False

--freeze_decoder_except_cross_attention, -freeze_decoder_except_cross_attention

Freeze decoder self-attention, feedforward, sandwich-norm post-branch norms (where present), and the vocabulary output projection, but keep cross-attention trainable. Useful for adapting how decoder attends to encoder representations while keeping decoder’s internal processing frozen. Adapters remain trainable if configured. Mutually exclusive with –freeze_decoder and –freeze_cross_attention.

Default: False

The beta2 parameter used by Adam.
